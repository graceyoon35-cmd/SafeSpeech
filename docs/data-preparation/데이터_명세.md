# SafeSpeech 데이터 명세

작성: 1학년 A (데이터, 환경, 재현성) / 갱신: 2026-11-10

이 문서는 어떤 데이터가 있고, 어디에 두고, 어떻게 식별하는지를 한곳에 모은 것입니다. 파일별 상세는 `SafeSpeech_data_list.csv`에 있습니다.

표시 규칙
- 측정: 파일에서 직접 읽은 값
- 문서 기준: 팀 문서에 적힌 값을 옮겨 적은 것. 직접 측정하지 않았음

## 2. 샘플레이트 규칙

| 언어, 모델 | 샘플레이트 | 비고 |
|---|---|---|
| 영어, Bert-VITS2 (LibriTTS) | 24000 Hz | 원본 168개 모두 측정으로 확인 |
| 한국어, MeloTTS | 44100 Hz | 학습용 복사본(`data/melo_ft/`)도 44100 Hz로 변환됨 |
| XTTS-v2 합성 출력 | 24000 Hz | 영어, 한국어 공통 |
| 한국어 실제 녹음 원본 | 녹음 장치 값 | 파일마다 측정해서 기록 |
| 한국어 보호 음성 | 입력과 같음 | 내부에서 44100으로 계산하고 입력 Hz로 저장 |

- STOI 평가는 두 음성의 샘플레이트와 샘플 수가 같아야 합니다. 다르면 거부되며 자동 변환이 없습니다.
- XTTS(24000)와 MeloTTS(44100) 결과를 STOI로 비교하려면 어느 쪽에 맞출지 팀이 정해야 합니다.
- 영어와 한국어 음성을 섞어서 평가하지 않습니다.

## 4. 파일을 식별하는 방법

- 파일 ID: 확장자를 뺀 파일 이름 (예: `5339_14133_000002_000003`)
- 보호 음성 ID: 원본 ID 뒤에 조건을 붙임 (예: `5339_14134_000092_000003_SPEC_iter10`)
- 해시: SHA-256. `SafeSpeech_data_list.csv` 170행 모두 비고 열에 있음 (영어 168개는 직접 계산, 보호 2개는 문서 기준)
- 한국어 발화 ID: `ko_s001_u001` 형식. `s001`은 실명 대신 쓰는 가명
- 실명과 가명의 대응표는 저장소와 공유 폴더 밖에 따로 보관합니다.

## 5. 목록과 대본 파일 형식

| 파일 | 형식 |
|---|---|
| 영어 `filelists/*.cleaned` | `경로\|화자\|EN\|문장\|음소\|톤\|word2ph` (7칸) |
| 영어 `libritts_train_text.txt` | `경로\|화자\|EN\|문장` (4칸) |
| 영어 `libritts_test_text.txt` | `경로\|화자\|문장` (3칸) |
| 한국어 `metadata.list` | `경로\|화자\|KR\|문장` (4칸) |
| 한국어 `transcripts.csv` | 머리글 `file,text` |
| 합성 결과 `metadata.csv` | 머리글 `reference, sentence_id, text, output` |

## 6. 작업별 입력과 출력

| 작업 | 스크립트 (브랜치) | 입력 | 출력 |
|---|---|---|---|
| 모델 받기 | `scripts/download_setup_models.py` (metrics 이후) | 없음 | 모델 파일 8개를 `checkpoints/` 등에 저장, 해시 확인 |
| GPU 점검 | `scripts/check_gpu_audio.py` | 없음 | 화면에 JSON (`status: PASS`) |
| 영어 섭동 smoke | `scripts/smoke_perturbation.py` | 학습 목록에서 1초 이상 가장 짧은 영어 1개를 자동 선택 | `runs/smoke_<시각>/protected.wav`, `perturbation.pt`, `report.json` |
| 평가 smoke | `scripts/smoke_evaluation.py` (metrics) | 기준 WAV 1개 (후보 WAV는 선택) | `runs/evaluation_smoke_*/report.json` |
| Gaussian 변환과 STOI | `scripts/run_experiment.py <설정.json>` (metrics) | 설정 JSON, 원본, 보호, 합성 WAV 경로 | `runs/experiment_*/report.json`, `transformed.wav` |
| 강건성 변환 | `scripts/run_robustness_sweep_b.py` (robustness) | sweep 설정 JSON | 변환 WAV, MP3, 조건표, 평가 쌍 목록 |
| 한국어 SPEC 1회, 10회 | `scripts/run_korean_melo_spec.py` (spec-perturbation) | 입력 JSON, assets 폴더 | 위 3절의 실행 결과 폴더 |
| 한국어 보호 (200회) | `melo_kr/protect_melo.py` (melo-kr) | 음성 폴더 | 보호 WAV(PCM16), `report.json` |
| 파인튜닝 데이터 준비 | `melo_kr/prepare_finetune.py` (melo-kr) | 음성 폴더, 대본 | `data/melo_ft/<이름>/` (44100 Hz) |
| MeloTTS 합성 | `melo_kr/synth_melo.py` (melo-kr) | 체크포인트, config | `runs/melo_attack/<이름>/`, `metadata.csv` |
| XTTS 제로샷 | `melo_kr/attack_xtts.py` (melo-kr) | 참조 WAV | `runs/xtts_attack/<이름>/`, `metadata.csv` |
| 채점 (SIM, ASR, CER) | `melo_kr/evaluate_kr.py` (melo-kr) | `metadata.csv`, 화자 원본 폴더 | `per_file.csv`, `summary.csv`, `summary.json` |

대부분의 스크립트는 출력 폴더가 이미 있으면 멈춥니다. 다시 돌릴 때는 다른 이름을 쓰세요.

## 7. 발표용 실험 조건 (지금까지 실행된 것)

한국어 합성 1문장으로만 실행된 조건입니다. 실제 사람 녹음이 아니고 복제 방어 효과를 측정한 것도 아닙니다.

| 항목 | 값 |
|---|---|
| 입력 | MeloTTS 합성 1문장, 44100 Hz, 약 4.45초, SHA-256 `ca64cfae3ff5c82c8e6080535b593bf58afc95bf191f60c6d63ff1d914d7041f` |
| 모델 | MeloTTS-Korean, 모델 화자 KR:0 |
| SPEC 설정 | seed 52, epsilon 8/255, 반복 1회와 10회 |
| STOI (보호 전후) | 1회 0.9962, 10회 0.8757 |
| 보호 후 최대 변화량 | 1회 0.00317, 10회 0.03140 |
| 강건성 변환 | Gaussian std 0.001, 0.005, 0.01 (seed 42, 43, 44), MP3 32, 64, 128 kbps, 리샘플링 8000, 12000, 16000 Hz, 총 15조건 |
| 반복 | 조건마다 2회 (같은 조건의 재현성 확인이며 독립된 표본이 아님) |
| 자동 테스트 | spec-perturbation 35개, robustness 29개 통과 (팀 기록) |

STOI는 명료도 지표입니다. 높다고 해서 복제를 막았다는 뜻이 아닙니다. 변환 후 STOI, SIM, CER, MCD, WER은 아직 측정하지 않았습니다.

## 9. 아직 없거나 정해지지 않은 것

- 한국어 실제 녹음, 녹음자, 동의서
- 한국어 대본의 사람 검수, 한국어 train, validation, test 나눔
- 복제 합성 음성 (모델 담당)
- MeloTTS 학습 설정 파일 `config.json` (`prepare_finetune.py`가 만들지 않음)
- `filelists/libritts_train_asr.txt.cleaned`가 가리키는 `data/LibriTTS/protected/clean/` 108개 파일
- 사전 계산 파일 `*.bert.pt`, `*.spec.pt` (전체 데이터 기준)
- 사용 허가: 영어는 CC BY 4.0이라 출처 표시가 필요하고, 한국어 녹음은 동의서가 필요합니다. 자세한 내용은 `개인정보_저작권_메모.md`
