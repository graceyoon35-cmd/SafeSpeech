작성일: 2026-11-03 · 작성: 1학년 A(데이터·환경·재현성) · 상태: 초안

## 2. 팀이 결정해야 할 것

### 2.1 XTTS-v2를 이 프로젝트에 써도 되는가

CPML은 직간접적으로 대가를 받지 않는 연구·실험·테스트를 비상업 용도로 인정합니다. 반면 수익 활동과 **정부 지원금으로 직접 운영되는 프로젝트**는 비상업에서 제외합니다.

- 확인할 것: 이 프로젝트에 정부 재원 지원금, 연구비, 상금 등 대가가 걸려 있는지
- 걸려 있다면: XTTS를 쓰기 전에 지도교수에게 확인합니다.
- 어느 경우든: 앱·서비스에는 넣지 않습니다. XTTS 합성 음성을 넘길 때는 약관 URL을 함께 전달합니다.

### 2.2 한국어 녹음은 누구 목소리로 하는가

목소리는 특정인을 알아볼 수 있어 개인정보로 다루는 것이 안전합니다. 이 프로젝트는 그 목소리를 복제하는 실험이라 일반 녹음보다 위험이 큽니다.

**녹음 전 동의서에 넣을 항목**

1. 목적: 음성 보호 기술 평가, 그 과정에서 복제 합성 음성을 만든다는 사실
2. 범위: 어떤 모델에 넣고 누가 접근하는지
3. 공개 여부: 원본·보호·합성 음성을 공개하지 않거나, 공개한다면 어디까지인지
4. 보관: 저장 위치와 프로젝트 종료 후 삭제 시점
5. 철회: 언제든 동의를 철회하고 삭제를 요청할 수 있다는 점

**관리 규칙**

- 파일명과 목록표에는 실명 대신 `S01` 같은 가명을 씁니다.
- 공인이나 유명인의 음성, 인터넷에서 받은 음성은 쓰지 않습니다.
- 발표에서 합성 음성을 틀려면 녹음자에게 따로 동의를 받습니다.

## 3. 저장소에서 발견한 위험

| 위험 | 내용 | 제안 |
|---|---|---|
| 실제 목소리 유출 | `/data/korean/` 제외 규칙은 `feature/melo-kr`에만 있음. `master`, `feature/data-preparation`, `feature/bert-vits2`에는 `.gitignore` 자체가 없음 | 규칙을 공통 브랜치에 반영하기 전에는 다른 브랜치에서 `git add .` 금지 |
| 출처 기록 누락 | `DATA_ATTRIBUTION.md`는 문서에서 언급되지만 저장소의 어느 브랜치 루트에도 없음. 문서 기준으로 각 실행 폴더에만 있음 | 저장소에도 출처 문서를 하나 추가 |
| 개인 경로 노출 | 공개 문서 `QUICKSTART_KO.md` 등에 팀원 이름이 든 경로(`/mnt/c/Users/...`)가 있음 | 해당 팀원에게 알리고 `<저장소 경로>`로 교체 검토 |
