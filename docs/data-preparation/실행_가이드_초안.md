## 2-1. 언어·모델별 샘플레이트

**"기본값 24000"은 영어(LibriTTS) 경로에서만 맞습니다.** 한국어 MeloTTS 경로는 44100입니다. 두 경로의 음성을 섞어 평가하지 마세요.

| 언어 | 모델·단계 | 샘플레이트 | 근거 | 확인 수준 |
|---|---|---|---|---|
| 영어 | Bert-VITS2 (LibriTTS) 입력·섭동 출력 | **24000 Hz**, 모노 | `bert_vits2/configs/libritts_bert_vits2.json`, `cmu_arctic_bert_vits2.json`의 `sampling_rate`. 원본 168개 모두 24000 Hz·모노·PCM_16 | 설정 파일과 실제 파일 168개 확인 |
| 영어 | Bert-VITS2 범용 `config.json` | 44100 Hz | `bert_vits2/configs/config.json` | LibriTTS 실험에는 쓰지 않음 |
| 영어·한국어 | XTTS-v2 합성 출력 | **24000 Hz** | `melo_kr/attack_xtts.py`가 24000으로 저장 | 코드 확인, 실행 미검증 |
| 한국어 | MeloTTS-Korean 모델, 파인튜닝 학습 데이터 | **44100 Hz**, 모노, PCM_16 | `melo_kr/prepare_finetune.py`의 `MELO_SR = 44100`, `melo_kr/README_KO.md` | 코드·README 확인, 실행 미검증 |
| 한국어 | 녹음 원본 | 정해져 있지 않음 (녹음 장치 값) | README는 "2~10초, 모노 권장"만 명시 | 파일마다 측정해서 목록표에 기록 |
| 한국어 | 섭동(protected) 출력 | 입력과 같음 | README: 섭동은 입력 샘플레이트 그대로 만듦 | README 설명 |
| 공통 | STOI 평가 | 두 음성의 샘플레이트·샘플 수가 같아야 함 | `scripts/run_experiment.py`, 테스트 9개(다른 샘플레이트 거부) | 테스트로 확인 |

- 한국어 경로에서는 한 사람의 음성이 **샘플레이트가 다른 파일 세 종류**로 생길 수 있습니다: 녹음 원본, 보호 음성(입력과 같음), `data/melo_ft/`의 44100 Hz 학습용 복사본(원본은 건드리지 않음).
- XTTS 합성(24000)과 MeloTTS 계열(44100)을 STOI로 비교하려면 샘플레이트가 같아야 합니다. 평가 스크립트에는 **자동 변환이 없고 다르면 거부**하므로, 어느 쪽에 맞출지 팀 합의가 필요합니다.
- 모든 파일의 샘플레이트는 추정하지 말고 파일에서 읽은 값을 `SafeSpeech_data_list.csv`에 적습니다.

## 3. Windows WSL: CPU 평가

확인 수준: WSL Ubuntu 22.04에서 10/27 실행, 테스트 9개 통과 기록. GPU 없는 PC도 됩니다.

PowerShell이 아니라 **Ubuntu 터미널**에서 실행합니다.

```bash
sudo apt-get update
sudo apt-get install -y python3-venv python3-pip libsndfile1
python3 --version    # 3.10 확인
python3 -m venv "$HOME/.venvs/safespeech-cpu"
source "$HOME/.venvs/safespeech-cpu/bin/activate"
python -m pip install -r requirements-evaluation-smoke.txt
python -m pip check
python scripts/smoke_evaluation.py
python scripts/run_experiment.py experiments/gaussian_smoke.json
python -m unittest discover -s scripts -p 'test_*.py' -v
```

결과는 새 `runs/experiment_*` 폴더에 저장됩니다.

## 4. Mac: CPU 평가

확인 수준: macOS arm64, Python 3.10.11에서 팀원 실행 기록. Python 3.13은 쓰지 않습니다.

```bash
python3.10 -m venv .venv
.venv/bin/python -m pip install -r requirements-evaluation-smoke.txt
.venv/bin/python -m pip check
```

**Mac에서 하지 않는 것**: CUDA 섭동 생성과 학습은 지원 대상이 아닙니다. XTTS는 Mock 테스트만 했습니다. 실제 음성 평가는 WSL에서 만든 WAV를 가져와서 합니다(`docs/SPEC_PAIR_IMPORT_KO.md`).

## 7. 한국어 경로 (feature/melo-kr)

확인 수준: 무작위 가중치로 코드 경로만 검증. 환경 3개가 필요하며, 전체 절차는 `melo_kr/README_KO.md`를 따릅니다.

| 환경 | 경로 | 하는 일 |
|---|---|---|
| 기본 | `~/.venvs/safespeech` | 가중치 다운로드, 섭동 생성, 채점. `openai-whisper speechbrain jiwer` 추가 설치 |
| XTTS | `~/.venvs/xtts` | 제로샷 공격 |
| MeloTTS | `~/.venvs/melo` | 파인튜닝 공격. Python 3.10 권장 |

**MeloTTS 설치 전에 먼저 할 것 (처음 한 번)**

`third_party/MeloTTS`는 저장소에 들어 있지 않습니다(`feature/melo-kr`의 `.gitignore`가 `/third_party/`를 제외). 저장소 루트에서 직접 내려받은 뒤에 설치합니다. 출처는 `melo_kr/README_KO.md`이고, 아직 실행해 보지 않았습니다.

```bash
git clone https://github.com/myshell-ai/MeloTTS third_party/MeloTTS
source ~/.venvs/melo/bin/activate        # 3.10 가상환경
pip install torch==2.7.1 torchaudio==2.7.1 --index-url https://download.pytorch.org/whl/cu128
pip install -e third_party/MeloTTS
python -m unidic download
```

- clone한 시점의 커밋이 고정되어 있지 않으므로, 실행 기록에 `git -C third_party/MeloTTS rev-parse HEAD` 결과를 남깁니다.
- 한국어 G2P가 쓰는 MeCab-ko는 Python 3.10에서만 미리 빌드된 패키지로 설치됩니다(3.13은 빌드 실패, README 기록).

**문서끼리 다른 점 (팀 결정 필요)**

- XTTS 환경 위치: `~/.venvs/xtts`와 `.venv-xtts`
- XTTS 패키지: `coqui-tts[ko]`(버전 미고정)와 `coqui-tts==0.28.0`
- `third_party/MeloTTS`의 커밋과 평가 패키지 버전이 고정되어 있지 않음
