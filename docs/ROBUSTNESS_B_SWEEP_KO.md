# 2학년 B: 조건별 변환과 재실행 검증

실제 원본·SPEC 보호 음성 한 쌍에 같은 변환 조건을 적용하고, 동일 조건을 두 번 실행해
파일 해시가 일치하는지 확인합니다. 기존 변환 모듈과 run_pair를 재사용합니다.

## 시작용 조건

| 종류 | 조건 | 개수 |
| --- | --- | --- |
| Gaussian | std 0.001, 0.005, 0.01 × seed 42, 43, 44 | 9 |
| MP3 | 32, 64, 128 kbps | 3 |
| 리샘플링 | 8000, 12000, 16000 Hz | 3 |

총 15조건 × 원본/보호 2역할 × 동일조건 2회 = WAV 60개, 중간 MP3 12개입니다.
여러 seed는 잡음 실현값을 바꾸며, 같은 seed의 두 번 실행은 재현성 확인입니다.
동일 조건 반복을 독립적인 발화 표본 또는 보호 효과의 통계 검증으로 세지 않습니다.
조건은 탐색용 예시이며 논문 재현 조건이나 팀 최종 합의 조건이라고 주장하지 않습니다.

## 실행

새 조건 목록을 가진 기존 pair manifest를 준비합니다. 오디오 경로는 그 manifest 기준입니다.

    python scripts/run_robustness_sweep_b.py manifest.json --repeats 2

run_sweep 내부는 읽은 manifest를 절대 오디오 경로로 정규화해 새 runs 폴더에 복사합니다.
기존 입력·설정·출력을 덮어쓰지 않습니다. runs/robustness_sweep_b_* 안에 저장되는 파일:

- manifest.json: 정확한 실험 설정 스냅샷
- repeat_01/, repeat_02/: 회차별 WAV·MP3·개별 보고서
- artifacts.csv: 조건/역할/회차, 전후 Hz·길이, 클리핑 수, 입력·출력 해시, 상대 파일 경로
- summary.json: 산출물 개수, 입력 보존, 동일조건 해시 비교, 실패 시 오류

summary의 PASS는 변환·저장·반복 재현성 확인에 한정됩니다.
STOI/SIM/MCD/WER 또는 보호 성능 점수는 계산하지 않습니다.
리샘플링 결과는 목표 Hz를 유지합니다. 평가 전 기준 음성 변환과 정렬 정책을 합의하세요.
잡음의 std는 진폭 단위이며 SNR dB 조건이 아닙니다.
실패하면 성공으로 숨기지 않고 FAIL 요약과 이미 만든 부분 결과를 남깁니다.

## 평가 담당자와 공유

새 runs/robustness_sweep_b_* 폴더 전체를 공유하세요. CSV의 경로는 해당 폴더 기준이므로
전체 폴더를 내려받으면 파일을 찾을 수 있습니다. 개별 보고서에는 생성 당시 절대 경로도 있습니다.
표에는 측정하지 않은 점수를 0으로 기입하지 않습니다.
여러 발화의 실제 SPEC 쌍이 마련되면 별도 발화 ID를 부여해 실험을 확대합니다.
