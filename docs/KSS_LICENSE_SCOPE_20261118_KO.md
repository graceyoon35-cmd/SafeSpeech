# KSS 사용 범위 확인 — 2026-11-18

이 기록은 공개 근거와 확인하지 못한 사항을 구분한다. 팀의 사용 승인이나 화자의 별도 동의를 생성하는 문서가 아니다.
사용자가 설명한 프로젝트 목적은 비상업적 대학 연구다.

## 확인한 공개 근거

1. [원 배포처 Kaggle 데이터 카드](https://www.kaggle.com/datasets/bryanpark/korean-single-speaker-speech-dataset),
   [내용을 확인한 원 배포처 색인 페이지](https://www.kaggle.com/bryanpark/korean-single-speaker-speech-dataset/kernels).
   원 저자의 설명은 한국어 TTS 데이터라는 목적과 비상업적 사용을 밝힌다. 라이선스 표기는 CC BY-NC-SA 4.0이다.
   직접 페이지 열기는 본문을 반환하지 않았고 Kaggle API 두 경로도 404였다.
   따라서 원 배포 설명은 웹 검색 색인으로 확인했으며, 현재 로그인 후 화면/계약을 확인했다고 주장하지 않는다.
2. [실제 사용한 미러의 고정 리비전 카드](https://huggingface.co/datasets/Bingsu/KSS_Dataset/tree/48fdfd7ab1dbc1a62e4e8a8b9f4c360259d51d3c).
   이 카드는 내려받아 SHA-256을 기록했다. 미러를 원 배포자의 추가 승인으로 해석하지 않는다.
3. [CC BY-NC-SA 4.0 정식 약관](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en),
   Section 2(a), 2(b), 3. 브라우징 도구로 본문을 확인했다. 로컬 HTTP 다운로드는 403이었고 이 실패도 보존했다.
4. [저자의 KSS 예제 저장소](https://github.com/Kyubyong/kss).
   저장소 코드의 Apache-2.0을 데이터의 라이선스로 적용하지 않는다.

## 작업별 판정

| 작업 | 공개 근거로 판단 가능한 범위 | 남은 미확인 사항 / 이번 실행 |
|---|---|---|
| 내부 SPEC 변형 | 비상업적 복제·변형에 대한 저작권상 조건부 근거가 있음 | 별도 팀 확인과 청취 검수는 없음. KSS 실제 SPEC는 미실행 |
| 내부 TTS 파인튜닝 | 원 배포의 TTS 목적 및 비상업 조건이 일반 TTS 연구의 근거를 제공 | 특정 화자 모사까지 추가 승인됐다고 기록하지 않음. KSS 학습 미실행 |
| 학습 모델의 합성 | TTS 연구 과정의 합성이라는 해석은 가능하나, 용도·공개 방식까지 명시한 별도 허가를 찾지 못함 | KSS 화자 모사/공개 권한은 미확인. 이번 학습·평가는 공개 사전학습 모델의 합성 데이터로 대체 |
| 원본/보호 WAV 외부 공유 | 저작권상 비상업·출처 표시·변경 표시 및 적용되는 동일조건 의무를 검토해야 함 | 외부 업로드하지 않음. 공개 상태를 자동 승인하지 않음 |
| 체크포인트/합성물 외부 공개 | 학습 가중치·생성물이 언제 데이터의 변형물인지 약관만으로 일괄 확정할 수 없음 | 미확인. 화자 관련 권리와 공개 목적을 별도로 검토해야 함 |

CC 약관의 저작권상 허용과 화자의 개인정보·인격권 등은 동일하지 않다. 약관이 이런 권리를 모두 부여한다고 판단하지 않는다.
반대로 모든 내부 TTS 연구에 반드시 별도 화자 동의서가 필요하다는 결론도 내리지 않는다.
이번 기록은 사용 범위를 검토하는 근거이며 팀 승인 사실을 대체하지 않는다.

## 데이터 상태와 실행 제한

- 기존 KSS 200개의 WAV·대본·해시·140/30/30 split은 재검증했다.
- 원본 `usage_status=pending_team_confirmation`, `research_use_permitted=false`,
  `transcript_verified=false`를 변경하지 않았다. 팀의 별도 기록이 없다는 사용자 답변도 유지했다.
- 전처리 결과는 읽기만 한 원본과 별도 디렉터리에 만들었다. 텍스트/BERT 특징 생성은 청취 검수가 아니다.
- 실행기는 원본의 허가·검수 선언을 재검사한다. 새 config의 bool 하나를 바꾸어 이 검사를 우회할 수 없다.
- 미검수 KSS 실행은 실제로 거부됐다. 이를 라이선스상 모든 연구가 금지된다는 의미로 표현하지 않는다.
- 실제 KSS 실험에 앞서, 팀이 위 근거에 따라 적용할 사용 범위를 기록하고 발화별 청취 결과를 입력해야 한다.
  추가 허가가 필요한지 여부도 해당 사용 범위별로 판단하며, 없는 허가를 있는 것으로 가정하지 않는다.
